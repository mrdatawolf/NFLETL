Everything else in this directory is sample/source data used for local
development and is intentionally **not** committed (see the `Examples/*`
rule in `.gitignore`) — it's real third-party business data used as a
placeholder, not NFL's own data. See the "Sample data" section in the
top-level README for details and where the current tally sample files come
from.

To run this project locally, populate `Examples/tally/` (and any other
configured source paths) yourself; a fresh clone will not have them.
